# JOVI - Luz Dinâmica

## Sobre o projeto

O projeto JOVI - Luz Dinâmica foi desenvolvido com o objetivo de apresentar uma proposta inovadora de funcionalidade para smartphones.

A Luz Dinâmica é uma solução de iluminação inteligente voltada para fotografias. A funcionalidade busca adaptar a iluminação do ambiente para melhorar a experiência do usuário e a qualidade das fotos.

O projeto também teve como objetivo aplicar conhecimentos de desenvolvimento Front-end, estilização e criação de interfaces modernas e responsivas.


## Funcionalidades

O site possui as seguintes seções:

Apresentação da funcionalidade Luz Dinâmica;
Explicação sobre a solução proposta;
Objetivos do projeto;
Público-alvo;
Modo fotografia;
Galeria com imagens da interface;
Apresentação da equipe responsável pelo projeto;
contato;
Navegação entre as seções da página.



## Tecnologias utilizadas

Para o desenvolvimento do projeto foram utilizadas as seguintes tecnologias:

HTML5;
CSS3;
Tailwind CSS.



## Objetivo

O principal objetivo do projeto foi criar uma proposta inovadora para smartphones, desenvolvendo uma interface moderna e aplicando conceitos de desenvolvimento Front-end e estilização.

A solução foi pensada para usuários que gostam de tecnologia, personalização e fotografia.



## Público-alvo

A funcionalidade Luz Dinâmica foi desenvolvida pensando principalmente em:

Universitários;
Influenciadores;
Pessoas que gostam de personalização;
Pessoas interessadas em fotografia e experiências visuais.
